# 职见 · AI 求职探索

面向高校学生与应届毕业生的 AI+就业服务课程原型，部署在 GitHub Pages。

## GitHub Pages 部署

直接打开 `index.html` 预览。部署到 GitHub Pages：将本目录中的文件和隐藏目录上传到仓库根目录；在 Settings → Pages 中把 Build and deployment 的 Source 设为 GitHub Actions；推送到 `main` 分支后，仓库中的 `.github/workflows/pages.yml` 会自动发布网页。

## BossHunter 本地 CSV 导入

1. 在 BossHunter 本机工作台中选择需要的岗位，导出格式选 `CSV`，导出筛选结果、所选岗位或全部岗位。
2. 打开本网站，在“导入 BossHunter 本地导出”处选择刚导出的 CSV。
3. 网站只在当前浏览器读取文件，展示和筛选导入的职位；可用“清除导入”清除本地记录并恢复演示数据。

导入器只保留岗位 ID、平台、职位、公司、薪资、城市、经验、学历、JD 和原职位链接；丢弃 HR 姓名/职位/活跃度、简历路径、招呼语和评分字段。数据保存在当前浏览器的 `localStorage`，不会上传到 GitHub Pages、BossHunter API 或其他服务器，也不会显示给其他访客。该功能是用户主动选择文件的本地导入，不直接调用 BossHunter 的本机 Agent API。

本地导入不会授予对招聘平台数据的再发布权。如果要把真实职位作为公共内容发布到网站，需要先取得相应平台许可或使用明确允许再发布的数据源。此原型不抓取求职者评论，不展示个人评论或个人资料。

## 功能

- 关键词、城市、岗位方向、月薪下限筛选；支持薪资和评价分排序。
- 查看岗位描述、要求、来源职位链接；评价仅以明确标注的虚构样例展示。
- 收藏岗位保存在当前浏览器。
- 支持 BossHunter 导出的 CSV 本地导入；导入数据与默认演示数据分开标注。
- 响应式布局；纯前端，无服务端账号或简历收集。

## 数据说明

首次打开时显示虚构职位和虚构评价，仅供课程演示。导入后的真实职位只会在导入文件的那个浏览器中显示。职位信息仍应回原平台核实更新时间和准确性；不得把没有授权的职位或个人信息提交到公共网站。
