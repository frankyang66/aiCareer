# 职见 · AI 求职探索（课程演示原型）

面向高校学生与应届毕业生的 AI+就业服务场景探索。纯静态网页，可直接部署到 GitHub Pages。

## 运行

直接打开 `index.html` 预览。部署到 GitHub Pages：新建仓库，将本目录中的文件和隐藏目录一并上传到仓库根目录；在 Settings → Pages 中将 Build and deployment 的 Source 设为 GitHub Actions；推送到 `main` 分支后，仓库中的 `.github/workflows/pages.yml` 会自动发布网页。

## 功能

- 按关键词、城市、岗位方向、月薪下限筛选；支持薪资和评价分排序。
- 查看岗位描述、要求、匹配理由与企业评价摘要。
- 收藏岗位保存在当前浏览器的 localStorage 中。
- 适配移动端；纯前端，无服务器、账号或简历收集。

## 数据与边界

页面所有公司、岗位、薪资、评分、评价数量和评价摘要均为虚构的演示样例，不代表真实招聘信息或真实评价。没有从 BOSS 直聘、前程无忧等平台爬取数据，也没有收集求职者信息。生产版本应先获得数据授权，使用开放接口或合作数据源，并落实来源标记、更新时间、纠错和删除机制。不要用此原型的模拟评分进行真实求职决策。
